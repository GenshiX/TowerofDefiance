## Tester
- Marshall

## What They Understood Quickly
- The units were attacking enemies automatically.
- Currency increased as enemies were defeated.

## Where They Got Confused
- He did not immediately know he could click units or upgrade windows.
- The white squares behind units were unclear and did not obviously look like upgrade buttons.
- The game ended too quickly and felt too easy.

## Changes Made After Testing
1. Added clearer on-screen instructions explaining that grey units and upgrade windows can be clicked.
2. Adjusted the UI language so the player understands the goal is to buy all units and upgrades.
3. Planned or adjusted tuning so the game takes longer to complete.

## Changes We Would Make With More Time
- Add labels directly on each upgrade window.
- Add hover/click animations for purchase windows.
- Improve art so upgrade windows look like intentional shop spaces instead of plain placeholders.
