# Ground Tower Idle

## Team Members
- Sean Sikora
- Dalton Lybarger

## Description
Ground Tower Idle is a short 2D idle game built in Unity. Units automatically attack enemies to earn currency. The player uses that currency to buy more units and upgrades.

## Controls
- Click Archer to buy Archer.
- Click Mage to buy Mage.
- Click upgrade windows to buy upgrades.

Keyboard backup controls:
- A: Buy Archer
- M: Buy Mage
- 1-6: Buy upgrades

## Objective
Earn currency and fully upgrade the ground floor.

## How to Win
Buy all available ground floor units and upgrades:
- Archer
- Mage
- Sling upgrades
- Archer upgrades
- Mage upgrades

## Lose Condition
This build does not use a traditional lose condition because it is an idle game focused on progression.

## Known Issues
- This build focuses on the ground floor only.
- Audio uses simple generated sound effects.
